# Image Processing & Face Symmetry

Coursework and a term project for an image processing course (EE604): weekly homework/assignments in classical image processing, plus a group project measuring facial symmetry from photos using facial landmark detection.

## Contents

- **`Project/`** — term project: facial symmetry analysis using dlib's 68-point facial landmark predictor (`shape_predictor_68_face_landmarks.dat`) to locate landmarks and measure left/right symmetry. Writeup: `EE604_project_group6.pdf`. (Note: `code.py` in this folder is currently empty — the implementation lives in the submitted report/notebook referenced there; sample images are in `demo_data/`.)
- **`course_hw/HW1`–`HW9`** — weekly homework, each with its own `code.py`/`test.py` and submitted PDF writeup.
- **`course_assignements/Assignment_1`, `Assignment_2`** — two larger graded assignments, each with code and a submitted PDF.

## Status

Academic coursework archive, kept for reference rather than active development. Of the contents here, `Project/` (face symmetry) is the most self-contained piece; the `course_hw` and `course_assignements` folders are per-assignment submissions.
